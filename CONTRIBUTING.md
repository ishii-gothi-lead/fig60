# Contributing to Fig 60

Thank you for your interest in contributing to **Fig 60**! 

Fig 60 is a zero-cost, browser-based, human-only micro-video platform. We prioritize user privacy, zero surveillance, and complete serverless independence by leveraging client-side WebAssembly and P2P routing.

---

### 📜 Code of Conduct & Mission Alignment

By contributing to this repository, you agree to uphold our core principles:
1. **Human-Only & Anti-AI:** All core platform design prioritizes authentic human engagement over algorithmic optimization.
2. **Zero-Surveillance:** No hidden tracking, telemetry, or invasive analytics.
3. **Open & Decentralized:** Code must remain fully compatible with GNU AGPLv3 licensing.

---

### 🚀 Getting Started

#### Prerequisites
* Node.js (v18+ recommended) or any static HTTP server.
* A modern browser supporting WebAssembly and SharedArrayBuffer (e.g., Chrome, Firefox, Edge, Safari).
