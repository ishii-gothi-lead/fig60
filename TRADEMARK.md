# Fig 60 Trademark Policy

## Purpose
While the source code for Fig 60 is licensed under the GNU AGPLv3, the name **Fig 60** and its associated logos represent a commitment to a human-only, surveillance-free micro-video canvas. This policy protects brand integrity and prevents misuse.

---

## Allowed Use
You are free to:
* Mention **Fig 60** when referring to this open-source project or its official code repository.
* Run modified or unmodified instances of the software for personal, community, or educational purposes.

---

## Brand Restrictions
You may **NOT** use the name "Fig 60" or official logos for any deployment, fork, or service that:
1. Serves commercial advertising, third-party user tracking, or data harvesting scripts.
2. Promotes, hosts, or distributes synthetic, automated, or AI-generated video content.
3. Imposes user subscription fees, paywalls, or commercial monetization mechanisms.

---

## Custom Branding for Forks
If you deploy a modified instance or a commercial platform using this source code, you must rebrand your instance (e.g., using a distinct name and logo) to ensure users are not confused regarding affiliation with the core Fig 60 project.
